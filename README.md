# Rift Breaker: Fist of the Hollow

A lightweight browser prototype for a new original mobile-action endless brawler.

## Features
- Endless wave survival combat
- Punch attack and enemy pressure
- Progression and upgrade loop
- Forge-style stat upgrades
- HUD and game-over flow
- Touch-friendly controls for mobile browsers
- Local high-score save using browser storage

## How to run
1. Open the project folder in a browser, or serve it locally.
2. If using a local web server:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit:
   ```text
   http://localhost:8000
   ```

## Controls
- Desktop:
  - Move: WASD or arrow keys
  - Punch: Spacebar
- Mobile:
  - D-pad on bottom-left
  - Punch button on bottom-right

## Notes
This is a playable prototype, not a full production game. It is designed to validate the core combat loop, progression feel, and game identity quickly.
